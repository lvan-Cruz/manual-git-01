# Introducción a Git #
**Git** es un sistema de control de versiones que permite registrar, organizar y gestionar los cambios realizados en un proyecto. Es muy utilizado en el desarrollo de software porque facilita el trabajo en equipo y permite recuperar versiones anteriores de los archivos.

---

Con Git, los desarrolladores pueden crear diferentes **ramas (branches)** para trabajar en nuevas funciones sin afectar directamente al proyecto principal. Ademas, cada cambio importante puede guardarse mediante un **commit**, lo que permite conocer que modificaciones se realizaron y cuando.

---

| Concepto | Descripcion |
| ------------- | :-------------: |
|Repositorio | 	Lugar donde se almacena el proyecto y su historial. |
| Commit | 	Registro de un conjunto de cambios realizados. |
|Branch | Rama independiente para desarrollar nuevas funciones. |
| Merge | 	Proceso de unir los cambios de diferentes ramas. |
